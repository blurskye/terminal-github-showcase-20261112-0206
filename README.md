# Orbit — a terminal-first task queue

**Public synthetic demo for exploring gh-dash and its companion tools.**
No production code, customer data, credentials, or real incident reports are included.

Orbit is a tiny Python task scheduler: predictable retries, readable status, and quiet defaults.

## Development

```sh
python3 -m unittest discover -s tests -v
```

## Roadmap

- Durable queue storage
- Searchable execution history
- Per-project notification settings
- Keyboard-first navigation

The pull requests, discussions and intentional CI failures in this repository are demonstration data.
